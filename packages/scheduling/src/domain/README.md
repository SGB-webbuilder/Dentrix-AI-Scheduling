# Scheduling models

Future value types for durations, procedure/resource requirements, provider timing, office-local time, availability snapshots, and candidate slots. Models should carry provenance and rule-version references when required for reproducibility.

Exact shapes, multi-procedure aggregation, assistant/chair timing, timezone/DST behavior, and external availability semantics require approved requirements and evidence. Do not copy a Dentrix DTO into the domain or embed patient identifiers.
