# AI reasoning evaluations

Reserved for synthetic soft-rule interpretation, ranking/explanation quality, ambiguity, injection, output validation, PHI minimization, unavailability, and deterministic hard-gate scenarios. Use property/acceptance rubrics tied to approved requirements, not brittle exact prose matches.

Offline contract tests cannot prove real model behavior. Remote Bedrock evaluations require approved client account/region/model access, cost limits, and safe logging; they must not run implicitly on a PR. No prompt or model call is implemented.
