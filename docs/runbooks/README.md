# Runbooks

These are preparation templates. Each operational runbook must later record its owner, scope/environment, prerequisites, safe commands, approval requirements, expected output, rollback/escalation, last drill date and evidence reference.

| Runbook | Current preparation |
| --- | --- |
| Incident and exposure response | [Template](incident-response.md) |
| Dentrix timeout/uncertain appointment | [Recovery template](booking-recovery.md) |
| Deployment/rollback | [Deployment guide](../deployment/deployment-guide.md); commands pending |
| Backup/restore and key recovery | Pending AWS/database design and restore drill |
| Secret rotation | Pending verified integration credential lifecycles |
| Audit sink failure | Pending immutable sink and fail-closed design |
| Access removal / handover | Pending identities and operational owner |

Do not place real incident evidence or credentials in these templates.
